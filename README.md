# Border Kit

Free, browser-only tools for travelling and living across European borders.

| Tool | What it does |
|---|---|
| [Fairfare Claims](claims/) | Checks flight (EU261) and train (Regulation 2021/782) delay compensation and drafts the claim letter |
| [Dayline](dayline/) | Tracks Schengen 90/180 days and days per country toward the 183-day tax residency line |
| [Dogs on Rails](dogs/) | Dog rules and costs on European rail operators, plus a border paperwork checklist |

Each tool is a single HTML file with no build step and no server. Data typed into Dayline and Dogs on Rails is saved only in the visitor's own browser (localStorage).

Rules were last checked in October 2026. Corrections are welcome: open an issue with a link to the operator's or regulator's page.

General information only, not legal, tax or veterinary advice.
